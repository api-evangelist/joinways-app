Joinways provides event venue management software and CRM, built by venue operators to streamline inquiries, proposals, scheduling, e‑signatures, and reporting. The SaaS platform serves venues in France, the United States, the United Kingdom, and Spain, offering integrations with email, calendars, accounting, and booking platforms. It aims to eliminate manual data entry, improve proposal turnaround, and centralize client history, supporting multilingual use and GDPR‑compliant data hosting in the EU.

**Areas:** Event Management · SaaS · CRM · Venue Software · Multilingual

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Joinways: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
